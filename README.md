# 👑 일곱 군주의 탁자

AI 군주 7명과 겨루는 브라우저 오토배틀러입니다. 상점에서 유닛을 사서 배치하면 전투는 자동으로 진행되고, 플레이어는 **군주 마나로 주문을 직접 시전해 전투에 개입**합니다. 배치는 전략, 주문은 전술.

**플레이:** https://yeonny3209.github.io/seven-lords-table/

외부 이미지나 서버 없이 `index.html` 파일 하나로 동작합니다. 내려받아 브라우저로 열어도 됩니다.

## 조작

| 동작 | 방법 |
|---|---|
| 유닛 구매 | 상점 카드 클릭 |
| 배치·이동 | 대기석/보드 유닛을 끌어다 놓기 (아래쪽 4줄) |
| 판매 | 상점이나 판매 칸으로 끌기, 또는 마우스를 올리고 `E` |
| 아이템 장착 | 왼쪽 보관함의 아이템을 유닛에 끌어다 놓기 |
| 새로고침 / 경험치 | `D` / `F` |
| 준비 완료 | `Space` |
| 주문 시전 | 카드 클릭 또는 `1` `2` `3` → 대상 클릭 (조준 중 0.25배속) |
| 대상 순환·시전·취소 | `Tab` · `Enter` · `Esc`/우클릭 |
| 주문서 (장착·강화·자동 시전) | `B` |
| 전투 속도 (1배·2배·즉시 결과) | `S` |

## 구현된 시스템

- **경제:** 기본 5골드, 이자(10골드당 1, 최대 5), 연승·연패 보너스, 레벨 1~9, 레벨별 상점 확률
- **공유 유닛 풀:** 40종(1코스트 12 · 2코스트 10 · 3코스트 8 · 4코스트 6 · 5코스트 4). AI 군주의 구매도 같은 풀에서 빠짐. 3개 합성 → ★2, ★3
- **시너지 12종:** 계열 6(화염·서리·숲·망령·기계·별빛) + 역할 6(수호자·돌격대·저격수·주술사·암살자·치유사), 2/4/6명 단계
- **자동 전투:** 8×7 사각 격자, 대각 이동, A* 경로 탐색, 0.1초 틱, 공격·피격 마나와 고유 스킬(효과 단위 데이터), 30초 제한 시간. 15초 이후에는 '연장전'으로 피해가 점점 커져 시간 초과가 드물어짐
- **군주 주문 16종:** 군주 마나(초당 1.5, 아군 처치 시 +1, 최대 10), 군주 유형 3종(전쟁·수호·책략)과 패시브, 슬롯 2칸(레벨 7에 3칸), 골드로 3단계 강화, 전투당 1회 주문 1장 제한, 주문마다 자동 시전 규칙(직접 시전보다 효과 10% 약함)
- **AI 군주:** 12명 명단 중 매 판 7명, 경제·레벨·집착·리롤·주문 성향과 판마다 소폭 변동. 화면 밖 AI끼리의 전투도 실제로 시뮬레이션. 쉬움·보통·어려움 난이도
- **라운드:** 1단계 몬스터 3라운드 → 대전·공용 선택(체력 낮은 순)·몬스터 라운드. 2·3·4단계 시작 시 증강 30종(주문 증강 8종) 중 선택
- **아이템:** 재료 8종, 조합 36가지 중 고유 효과 20종(군주의 인장 포함), 유닛당 최대 3개
- **기타:** 시드 기반 난수(같은 시드 = 같은 판), 라운드마다 자동 저장, 상대 군주 열람(보드·시너지·주문), 전투 후 유닛별 피해·주문 기여 통계, 밸런스 시뮬레이션 화면

## 밸런스 메모 (내장 시뮬레이션 기준)

레벨 7 무작위 보드 300판 기준으로 측정했습니다. 시간 초과는 약 4%, 시너지별 승률은 40~56% 범위입니다. 주문 효과는 같은 보드에서 한쪽만 AI 자동 시전으로 주문을 썼을 때 승률이 42%에서 53%로 오르는 정도(+11%p)입니다. 기획 목표(+15~25%p)보다 낮은데, 직접 시전하면 효과가 100%이고 대상도 더 정확하게 고를 수 있어 실제 차이는 이보다 큽니다. 게임 안의 **📊 밸런스 시뮬레이션**에서 직접 다시 측정할 수 있습니다.

## 파일 구조

`index.html`은 빌드 결과물입니다. 수정은 `src/`에서 하고 `node build.js`로 다시 묶습니다.

```
src/
  shell.html      화면 골격
  style.css       스타일
  00-core.js      시드 난수, 유틸
  01-data.js      설정값, 상점 확률, 시너지, 유닛 40종
  02-data2.js     아이템, 주문 16종, 군주 유형, 증강 30종, AI 군주 12명, 몬스터
  03-combat.js    전투 엔진: 준비, 능력치, 효과 기본 단위
  04-combat2.js   전투 엔진: 틱 진행, A*, 공격, 스킬
  05-spells.js    군주 주문 시전, 자동 시전 규칙, AI 시전
  06-game.js      게임 상태, 풀, 상점, 경제, 합성, 라운드, 저장
  07-ai.js        AI 군주 준비 단계(구매·레벨·배치·아이템·주문)
  08-render.js    캔버스 그리기와 전투 이펙트
  09-ui.js        패널과 툴팁
  10-modals.js    시작 화면, 증강, 공용 선택, 주문서, 결과
  11-flow.js      라운드 흐름과 전투 재생 루프
  12-input.js     끌어놓기, 주문 조준, 키보드
  13-sim.js       밸런스 시뮬레이션, 시작
```
