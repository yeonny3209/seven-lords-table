# 👑 일곱 군주의 탁자

AI 군주 7명과 겨루는 브라우저 오토배틀러입니다. 상점에서 유닛을 사서 배치하면 전투는 자동으로 진행되고, 플레이어는 **군주 마나로 주문을 직접 시전해 전투에 개입**합니다. 배치는 전략, 주문은 전술.

**플레이:** https://yeonny3209.github.io/seven-lords-table/

외부 이미지나 서버 없이 `index.html` 파일 하나로 동작합니다. 내려받아 브라우저로 열어도 됩니다.

## 조작

| 동작 | 방법 |
|---|---|
| 유닛 구매 | 상점 카드 클릭 |
| 배치·이동 | 대기석/보드 유닛을 끌어다 놓기 (아래쪽 4줄) |
| 판매 | 상점 위로 끌어다 놓기(판매 영역이 나타남), 또는 마우스를 올리고 `E` |
| 아이템 장착 | 보관함의 아이템을 유닛에 끌어다 놓기, 또는 아이템을 누른 뒤 유닛 누르기(모바일) |
| 아이템 해제·판매 | 유닛을 누르면 나오는 정보 창에서 '빼기' · '판매' |

| 준비 완료 | `Space` |

| 주문 시전 | 카드 클릭 또는 `1` `2` `3` → 대상 클릭 (조준 중 0.25배속) |
| 대상 순환·시전·취소 | `Tab` · `Enter` · `Esc`/우클릭 |

| 전투 속도 (1배·2배·즉시 결과) | `S` |

## 🌐 온라인 대결 (최대 8명)

시작 화면의 **온라인 대결**에서 방을 만들고, 친구는 4자리 방 코드로 입장합니다. 남는 자리는 AI 군주가 채우고, 사람끼리 만나는 대전은 실시간으로 진행됩니다(양쪽 모두 주문을 직접 시전). 연결이 끊긴 플레이어의 군주는 AI가 이어받습니다.

**방식:** 게임 규칙은 방장의 브라우저가 모두 계산하고(유닛 풀, AI 군주, 전투), 손님은 행동을 방장에게 보내 결과를 받아 그립니다. 서버는 방을 만들고 메시지를 전달할 뿐입니다. 그래서 **방장은 게임이 끝날 때까지 창을 닫으면 안 됩니다.** 온라인에서는 전투가 실시간(1배속)으로만 진행되고, 준비 시간은 60초입니다(모두 '준비 완료'를 누르면 바로 시작).

### 중계 서버 올리기

GitHub Pages는 정적 호스팅이라 WebSocket 서버를 돌릴 수 없어서, `server/`의 중계 서버를 따로 올려야 합니다. Node.js 18 이상이면 어디서나 되고, [Render](https://render.com) 무료 플랜 기준으로는 이렇습니다.

1. Render에서 **New → Blueprint** → 이 저장소 연결 (`render.yaml`을 자동으로 읽음). 직접 만든다면 Web Service, Root Directory `server`, Build `npm install`, Start `npm start`.
2. 배포가 끝나면 `https://이름.onrender.com` 주소가 생깁니다. 게임에서는 이걸 `wss://이름.onrender.com` 으로 입력합니다 (https 페이지에서는 `wss://`만 연결됩니다).
3. 접속 화면의 '서버 주소'에 한 번 입력하면 브라우저가 기억합니다. 친구에게는 주소를 미리 채운 링크를 보내면 편합니다: `https://yeonny3209.github.io/seven-lords-table/?server=wss://이름.onrender.com`
4. 기본 서버는 `src/12-net.js`의 `NET_DEFAULT_SERVER`(현재 `wss://seven-lords-table.onrender.com`)입니다. 바꾸려면 이 값을 고치고 `node build.js`.

무료 플랜은 한동안 쓰지 않으면 잠들어서 첫 접속이 30~60초 걸릴 수 있습니다. 내 컴퓨터에서 시험하려면:

```bash
cd server && npm install && npm start     # ws://localhost:8787
python -m http.server 8000                  # 다른 터미널에서 게임을 http://localhost:8000 으로 열기
```

## 구현된 시스템

- **경제:** 기본 5골드, 이자(10골드당 1, 최대 5), 연승·연패 보너스, 레벨 1~9, 레벨별 상점 확률
- **상점 9칸:** 유닛이 90종으로 늘어난 만큼 상점을 5칸에서 9칸으로 넓혀, 같은 유닛을 다시 만날 확률을 유닛 40종·5칸 시절 수준으로 되돌렸습니다
- **공유 유닛 풀:** 90종(1코스트 22 · 2코스트 20 · 3코스트 18 · 4코스트 16 · 5코스트 14). 계열마다 15종, 역할마다 14~17종. 강령술사의 뼈 졸개 같은 소환 유닛 포함. AI 군주의 구매도 같은 풀에서 빠짐. 3개 합성 → ★2, ★3
- **시너지 12종:** 계열 6(화염·서리·숲·망령·기계·별빛) + 역할 6(수호자·돌격대·저격수·주술사·암살자·치유사), 2/4/6명 단계
- **자동 전투:** 8×7 사각 격자, 대각 이동, A* 경로 탐색, 0.1초 틱, 공격·피격 마나와 고유 스킬(효과 단위 데이터), 30초 제한 시간. 15초 이후에는 '연장전'으로 피해가 점점 커져 시간 초과가 드물어짐
- **군주 주문 16종:** 군주 마나(초당 1.5, 아군 처치 시 +1, 최대 10), 군주 유형 3종(전쟁·수호·책략)과 패시브, 슬롯 2칸(레벨 7에 3칸), 골드로 3단계 강화, 전투당 1회 주문 1장 제한, 주문마다 자동 시전 규칙(직접 시전보다 효과 10% 약함)
- **AI 군주:** 12명 명단 중 매 판 7명, 경제·레벨·집착·리롤·주문 성향과 판마다 소폭 변동. 화면 밖 AI끼리의 전투도 실제로 시뮬레이션. 쉬움·보통·어려움 난이도
- **라운드:** 1단계 몬스터 3라운드 → 대전·공용 선택(체력 낮은 순)·몬스터 라운드. 2·3·4단계 시작 시 증강 80종(주문 증강 16종) 중 세 가지를 보고 선택
- **증강 80종:** 경제(황금알·전리품 사냥·리롤 장인 등), 전투(기습·증원군·불사조의 깃털·갑옷 관통 등), 주문(연쇄 시전·두 번째 기회·마나 저장고 등)
- **아이템:** 재료 8종, 조합 36가지 중 고유 효과 20종(군주의 인장 포함), 유닛당 최대 3개
- **부가 기능:** 📚 도감(유닛·시너지·주문·증강·아이템 검색), 🧩 자동 배치, 🔊 효과음(합성음, 음소거 가능), 🏅 전적 기록(이 브라우저에 저장), 📅 오늘의 도전(날짜가 시드)
- **기타:** 시드 기반 난수(같은 시드 = 같은 판), 라운드마다 자동 저장, 상대 군주 열람(보드·시너지·주문), 전투 후 유닛별 피해·주문 기여 통계, 밸런스 시뮬레이션 화면

## 밸런스 메모 (내장 시뮬레이션 기준)

레벨 7 무작위 보드 300판 기준(유닛 90종)으로 측정했습니다. 시간 초과는 약 4%, 시너지별 승률은 45~52% 범위입니다. 같은 보드에서 한쪽만 AI 자동 시전으로 주문을 쓰면 승률이 41%에서 56%로 올라(+15%p) 기획 목표(+15~25%p)의 하한에 들어옵니다. 게임 안의 **📊 밸런스 시뮬레이션**에서 직접 다시 측정할 수 있습니다.

## 파일 구조

`index.html`은 빌드 결과물입니다. 수정은 `src/`에서 하고 `node build.js`로 다시 묶습니다.

```
server/server.js  온라인 대결용 방 중계 서버 (Node + ws)
src/
  shell.html      화면 골격
  style.css       스타일
  00-core.js      시드 난수, 유틸
  01-data.js      설정값, 상점 확률, 시너지, 유닛 90종
  02-data2.js     아이템, 주문 16종, 군주 유형, 증강 80종, AI 군주 12명, 몬스터
  03-combat.js    전투 엔진: 준비, 능력치, 효과 기본 단위
  04-combat2.js   전투 엔진: 틱 진행, A*, 공격, 스킬
  05-spells.js    군주 주문 시전, 자동 시전 규칙, AI 시전
  06-game.js      게임 상태, 풀, 상점, 경제, 합성, 라운드, 저장
  07-ai.js        AI 군주 준비 단계(구매·레벨·배치·아이템·주문)
  08-render.js    캔버스 그리기와 전투 이펙트
  09-ui.js        패널과 툴팁
  10-modals.js    시작 화면, 증강, 공용 선택, 주문서, 결과
  11-flow.js      라운드 흐름과 전투 재생 루프
  12-input.js     끌어놓기, 주문 조준, 키보드
  12-audio.js     효과음 (Web Audio 합성)
  12-extras.js    도감, 전적 기록, 일일 도전, 자동 배치
  12-net.js       온라인 대결: 방·로비, 방장-손님 동기화, 전투 스냅샷
  13-sim.js       밸런스 시뮬레이션, 시작
```
